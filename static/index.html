    4 · 强度档（作用于对比 LoRA）

    「0 基线」始终会跑，用来判断对比 LoRA 到底改变了什么

    5 · LoRA 组合（2 个以上同时上场）

    一组里至少 2 个 LoRA，各自给权重 —— 几个 LoRA 会按顺序 串在模型链上同时生效（跟 ComfyUI 里叠几层权重 LoRA 加载器一样）。
    想验「底模 + 人物 + 风格」这种成套搭配，就在这儿配一组； 想单独看出某一个 LoRA 的强弱，用上面的「对比 LoRA」。
    组合里的 LoRA 如果填了触发词，会自动带上（见下一单元）。

    6 · 触发词（可选 · 需要才填）

    不少 LoRA 必须带触发词才生效。填在这里的词会自动加到提示词最前面， 只在该 LoRA 参与的那些图里出现；基线不会带上被对比 LoRA 的触发词， 这样差异才只来自 LoRA 本身。

    7 · 提示词（固定 seed，全部格子相同）

    8 · 测试工作流

    默认「引擎生成」—— 工具按上面「模型设置」现场搭一张 Krea2 扫档图， 什么都不用配，最稳。
    想用自己调好的：在 ComfyUI 里打开它 → 工作流 → 导出（API）， 存进 ComfyUI\user\default\workflows\，回来点「重扫」。 工具只会改写提示词、尺寸、seed / 步数 / CFG、出图前缀和 LoRA 链， 其余节点原样保留。

    这一块跟上面四个品质丹房不是一种东西： 品质丹房按「品质」分盒，而这里按 LoRA 在你 ComfyUI 里实际躺的那个文件夹 分盒 —— 一格一格就是你磁盘上的目录。所以在这里挪 LoRA 是真的在搬文件，搬完 ComfyUI 的目录也跟着变整齐。 已经定过级的 LoRA 挪位置时，它的品质标签会跟着一起走，不会掉级。
